# Case File and Escalation Summary Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn each diagnostic session into a *case* with a vehicle profile and an append-only event log, and produce a hand-off report (Markdown and self-contained HTML) summarizing what was tried, ruled out, and measured.

**Architecture:** `crank/case.py` wraps a `Session` with `vehicle.json` and `events.jsonl` and reads legacy files as synthesized events. `crank/summary.py` builds a pure, render-agnostic `Summary`. `crank/render.py` turns it into Markdown or HTML. The capture job gets an `on_done` hook so every saved capture lands in the log with a frozen verdict. `case_ui.py` is the new Case page; the phone remote gets a minimal quick add.

**Tech Stack:** Python 3.11, Streamlit, numpy, pytest (no new dependencies).

**Spec:** `docs/superpowers/specs/2026-10-11-case-file-design.md`

**Reference implementation:** Every code block below was prototyped in a scratch copy of this repo and passed 146 tests there (the 99 existing plus 47 new). Still follow the red/green steps in each task.

## Global Constraints

- Single user, local, file-based. No database, no accounts, nothing uploaded by the app.
- Existing sessions open as cases without migration or rewriting any file; the existing 99 tests stay green (three assertions in `tests/test_app.py` change because a case with no captures now lands on the Case page).
- A case with missing information says "not recorded"; reports contain only recorded content and never invent values.
- Simulator captures are labeled simulated in every report.
- Verdicts are presented as "the harness reported X", never as a diagnosis.
- Events are append-only; a correction is a new event. A damaged log line is skipped and counted.
- The HTML report is self-contained (inline CSS, no external requests) and escapes all user text.
- Event types: `symptom, observation, code_read, measurement, capture, change, hypothesis`. Unknown types in an existing log load without error.
- Commit messages end with the trailer `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus

- A truncated or garbage line in `events.jsonl`: skipped and counted, the rest loads, and the report notes it. Pinned in Tasks 1 and 2.
- Hostile text (`<script>`, `<img onerror>`) in a note, label or hypothesis reaching the HTML report: escaped, never executed. Pinned in Task 3.
- A brand-new case with no events and no vehicle, or only a vehicle profile: a valid summary and a report that says nothing has been recorded, not a plausible-looking empty hand-off. Pinned in Tasks 2 and 3.
- A capture that saved but whose analysis then fails: it still reaches the case log, and a failing log hook never breaks the capture. Pinned in Task 4.
- The phone and laptop (same process, different threads) appending at once: unique ids, no interleaved lines. Pinned in Task 1.

```python
"""A case: a session folder plus a vehicle profile and an append-only event log."""
from __future__ import annotations

import json
import threading
import time
from dataclasses import asdict, dataclass, field, fields
from pathlib import Path

from .store import Session, _read_json, _write_json

EVENT_TYPES = ("symptom", "observation", "code_read", "measurement", "capture", "change", "hypothesis")
HYPOTHESIS_STATUSES = ("open", "ruled_out", "confirmed")

# What a finding code suggests checking next (used to seed the hypotheses board).
SUGGESTIONS = {
    "no_signal": "Sensor power and ground, or reluctor wheel not turning",
    "harness_mismatch": "Wiring or connector between the sensor and the PCM pin",
    "ref_sag": "5V reference circuit and anything sharing it",
    "ground_lift": "PCM ground path under load",
    "unexplained_dropouts": "Sensor air gap, reluctor wheel, or the sensor itself",
    "no_sync_gap": "Wrong signal or wheel setting",
    "signal_clean": "PCM power, ground or calibration",
}

_lock = threading.Lock()


@dataclass
class Event:
    id: str
    ts: str
    type: str
    text: str = ""
    data: dict = field(default_factory=dict)
    refs: dict = field(default_factory=dict)
    synth: bool = False            # synthesized from legacy files; never written to disk

    def to_json(self) -> str:
        d = asdict(self)
        d.pop("synth")
        return json.dumps(d, separators=(",", ":"))

    @classmethod
    def from_dict(cls, d: dict) -> "Event":
        known = {f.name for f in fields(cls)} - {"synth"}
        return cls(**{k: v for k, v in d.items() if k in known})


@dataclass
class Vehicle:
    year: str = ""
    make: str = ""
    model: str = ""
    engine: str = ""
    transmission: str = ""
    mileage: str = ""
    modifications: str = ""
    vin: str = ""
    problem: str = ""

    @property
    def empty(self) -> bool:
        return not any(asdict(self).values())

    @property
    def title(self) -> str:
        t = " ".join(x for x in (self.year, self.make, self.model) if x)
        return t or "Vehicle not recorded"


def load_events(path: Path) -> tuple[list[Event], int]:
    """Read events.jsonl; damaged lines are skipped and counted."""
    events, skipped = [], 0
    try:
        lines = path.read_text().splitlines()
    except FileNotFoundError:
        return [], 0
    for line in lines:
        if not line.strip():
            continue
        try:
            d = json.loads(line)
            if not isinstance(d, dict):
                raise ValueError
            events.append(Event.from_dict(d))
        except (ValueError, TypeError):
            skipped += 1
    return events, skipped


def _validate(type_: str, text: str, data: dict) -> None:
    if type_ not in EVENT_TYPES:
        raise ValueError(f"unknown event type {type_!r}")
    if type_ == "measurement":
        try:
            float(data["value"])
        except (KeyError, TypeError, ValueError):
            raise ValueError("a measurement needs a numeric value") from None
        if not str(data.get("unit", "")).strip():
            raise ValueError("a measurement needs a unit")
        if not str(data.get("name", "")).strip():
            raise ValueError("a measurement needs a name")
    elif type_ == "hypothesis":
        if not str(data.get("title", "")).strip():
            raise ValueError("a hypothesis needs a title")
        status = data.get("status", "open")
        if status not in HYPOTHESIS_STATUSES:
            raise ValueError(f"unknown hypothesis status {status!r}")
        if status != "open" and not str(data.get("reason", "")).strip():
            raise ValueError("changing a hypothesis to ruled out or confirmed needs a reason")
    elif type_ in ("symptom", "observation", "change") and not text.strip():
        raise ValueError(f"a {type_} needs some text")
    elif type_ == "code_read" and not data.get("codes"):
        raise ValueError("a code read needs at least one code")


def capture_snapshot(analysis) -> dict | None:
    """Freeze the verdict and headline numbers so reports do not depend on later analysis changes."""
    if analysis is None:
        return None
    r = analysis.reports.get("ch1") or next(iter(analysis.reports.values()), None)
    return {
        "verdict": [{"code": f.code, "severity": f.severity, "title": f.title} for f in analysis.findings],
        "edges": r.n_edges if r else None,
        "revs_good": r.revs_good if r else None,
        "revs": r.revs if r else None,
        "rpm": round(r.rpm_median) if r and r.rpm_median else None,
        "ref_sag_mv": round(analysis.supply.get("ref_sag_mv", 0)),
        "gnd_dev_mv": round(analysis.supply.get("gnd_dev_mv", 0)),
    }


class Case:
    def __init__(self, session: Session):
        self.session = session
        self.path = session.path
        self.name = session.name
        self.skipped = 0

    # -- vehicle
    def vehicle(self) -> Vehicle:
        d = _read_json(self.path / "vehicle.json", {})
        if not isinstance(d, dict):
            return Vehicle()
        known = {f.name for f in fields(Vehicle)}
        return Vehicle(**{k: str(v) for k, v in d.items() if k in known})

    def set_vehicle(self, v: Vehicle) -> None:
        _write_json(self.path / "vehicle.json", asdict(v))

    # -- events
    @property
    def _events_path(self) -> Path:
        return self.path / "events.jsonl"

    def events(self) -> list[Event]:
        """Events from the log only (no legacy synthesis)."""
        events, self.skipped = load_events(self._events_path)
        return events

    def append(self, type_: str, text: str = "", data: dict | None = None,
               refs: dict | None = None) -> Event:
        data, refs = dict(data or {}), dict(refs or {})
        _validate(type_, text, data)
        with _lock:                               # id assignment and the write are one step
            existing, _ = load_events(self._events_path)
            nums = [int(e.id[1:]) for e in existing if e.id[:1] == "e" and e.id[1:].isdigit()]
            ev = Event(f"e{(max(nums) + 1) if nums else 1:04d}", time.strftime("%Y-%m-%dT%H:%M:%S"),
                       type_, text.strip(), data, refs)
            with open(self._events_path, "a") as f:
                f.write(ev.to_json() + "\n")
        return ev

    def append_capture(self, capture_id: str, label: str, analysis, sim: bool) -> Event:
        return self.append("capture", label, {"snapshot": capture_snapshot(analysis), "sim": sim},
                           {"capture": capture_id})

    def log_guided_step(self, step, values: dict) -> list[Event]:
        """Turn a saved guided-test step into events."""
        out = []
        for f in step.fields:
            v = values.get(f.key)
            if f.kind == "number":
                out.append(self.append("measurement", "", {
                    "name": f.label, "value": float(v), "unit": f.unit, "where": step.title,
                    "conditions": ""}, {"step": step.id}))
            elif f.kind == "bool":
                out.append(self.append("observation", f"{f.label}: {'yes' if v else 'no'}",
                                       {}, {"step": step.id}))
            elif f.kind == "text" and str(v).strip():
                out.append(self.append("observation", f"{f.label}: {str(v).strip()}",
                                       {}, {"step": step.id}))
        return out

    def hypotheses(self) -> dict[str, Event]:
        """Latest event per hypothesis id."""
        latest: dict[str, Event] = {}
        for e in self.all_events():
            if e.type == "hypothesis" and e.data.get("hid"):
                latest[e.data["hid"]] = e
        return latest

    def set_hypothesis(self, hid: str | None, title: str, status: str = "open",
                       reason: str = "", refs: dict | None = None) -> Event:
        hid = hid or f"h{len(self.hypotheses()) + 1}"
        return self.append("hypothesis", "", {"hid": hid, "title": title, "status": status,
                                              "reason": reason}, refs)

    # -- everything, including legacy files read as events
    def all_events(self) -> list[Event]:
        real = self.events()
        have_capture = {e.refs.get("capture") for e in real if e.type == "capture"}
        have_step = {e.refs.get("step") for e in real if e.refs.get("step")}
        extra: list[Event] = []
        for i, c in enumerate(self.session.list_captures()):
            if c["id"] in have_capture:
                continue
            extra.append(Event(f"legacy-c{c['id']}", (c.get("time") or "").replace(" ", "T"), "capture",
                               c.get("label", ""), {"snapshot": None, "sim": bool(c.get("sim"))},
                               {"capture": c["id"]}, synth=True))
        from .procedure import STEPS
        readings = self.session.readings()
        for step in STEPS:
            vals = readings.get(step.id)
            if not isinstance(vals, dict) or step.id in have_step:
                continue
            for f in step.fields:
                if f.key not in vals:
                    continue
                v = vals[f.key]
                if f.kind == "number":
                    extra.append(Event(f"legacy-{step.id}-{f.key}", "", "measurement", "",
                                       {"name": f.label, "value": v, "unit": f.unit,
                                        "where": step.title, "conditions": ""},
                                       {"step": step.id}, synth=True))
                elif f.kind == "bool":
                    extra.append(Event(f"legacy-{step.id}-{f.key}", "", "observation",
                                       f"{f.label}: {'yes' if v else 'no'}", {}, {"step": step.id}, synth=True))
                elif f.kind == "text" and str(v).strip():
                    extra.append(Event(f"legacy-{step.id}-{f.key}", "", "observation",
                                       f"{f.label}: {str(v).strip()}", {}, {"step": step.id}, synth=True))
        notes = self.session.notes()
        if notes.strip():
            extra.append(Event("legacy-notes", "", "observation", notes.strip(), {}, {}, synth=True))
        return sorted(real + extra, key=lambda e: (e.ts, e.id))


def suggest_hypotheses(codes, existing_titles=()) -> list[str]:
    """Suggested suspects for a verdict's finding codes, minus ones already on the board."""
    have = {t.strip().lower() for t in existing_titles}
    out = []
    for c in codes:
        s = SUGGESTIONS.get(c)
        if s and s.lower() not in have and s not in out:
            out.append(s)
    return out
```

```python
"""Build a structured, render-agnostic summary of a case. Pure: no I/O beyond reading the case."""
from __future__ import annotations

from dataclasses import dataclass, field

from .case import Case, Event, Vehicle
from .procedure import STEPS

NOT_RECORDED = "not recorded"


@dataclass
class Summary:
    case_name: str
    vehicle: Vehicle
    symptoms: list = field(default_factory=list)        # [{"ts", "text"}] newest first
    timeline: list = field(default_factory=list)        # [{"ts", "type", "line", "synth"}]
    ruled_out: list = field(default_factory=list)       # [{"title", "reason", "evidence"}]
    open: list = field(default_factory=list)            # [{"title", "reason", "evidence"}]
    confirmed: list = field(default_factory=list)
    measurements: list = field(default_factory=list)    # latest per name
    codes: list = field(default_factory=list)           # active codes from the latest code read
    captures: list = field(default_factory=list)        # [{"id","label","ts","sim","snapshot"}]
    before_after: list = field(default_factory=list)    # [{"change","before","after"}]
    not_tried: list = field(default_factory=list)       # guided step titles with no data
    attachments: list = field(default_factory=list)
    skipped_lines: int = 0

    @property
    def empty(self) -> bool:
        return self.vehicle.empty and not self.timeline


def _evidence(refs: dict) -> list:
    out = []
    for k in ("capture", "before", "after", "step"):
        if refs.get(k):
            out.append(f"{k} {refs[k]}")
    return out


def describe(e: Event) -> str:
    d = e.data
    if e.type == "measurement":
        where = f" ({d['where']})" if d.get("where") else ""
        cond = f", {d['conditions']}" if d.get("conditions") else ""
        return f"Measured {d.get('name')}: {d.get('value'):g} {d.get('unit')}{where}{cond}"
    if e.type == "capture":
        snap = d.get("snapshot")
        sim = " [SIMULATED]" if d.get("sim") else ""
        head = (snap["verdict"][0]["title"] if snap and snap.get("verdict") else "verdict " + NOT_RECORDED)
        return f"Capture {e.refs.get('capture', '?')}{sim}: {e.text or 'unlabeled'} — {head}"
    if e.type == "code_read":
        codes = ", ".join(c.get("code", "?") for c in d.get("codes", []))
        return f"Read codes: {codes}"
    if e.type == "hypothesis":
        s = d.get("status", "open").replace("_", " ")
        r = f" — {d['reason']}" if d.get("reason") else ""
        return f"Suspect '{d.get('title')}': {s}{r}"
    label = {"symptom": "Symptom", "observation": "Noted", "change": "Changed"}.get(e.type, e.type)
    return f"{label}: {e.text}"


def build_summary(case: Case) -> Summary:
    events = case.all_events()
    s = Summary(case.name, case.vehicle(), skipped_lines=case.skipped)

    s.symptoms = [{"ts": e.ts, "text": e.text} for e in reversed(events) if e.type == "symptom"]
    s.timeline = [{"ts": e.ts, "type": e.type, "line": describe(e), "synth": e.synth} for e in events]

    for e in case.hypotheses().values():
        row = {"title": e.data.get("title", ""), "reason": e.data.get("reason", ""),
               "evidence": _evidence(e.refs)}
        {"ruled_out": s.ruled_out, "confirmed": s.confirmed}.get(e.data.get("status", "open"), s.open).append(row)

    latest: dict[str, Event] = {}
    for e in events:
        if e.type == "measurement":
            latest[e.data.get("name", "")] = e
    s.measurements = [dict(name=n, value=e.data["value"], unit=e.data.get("unit", ""),
                           where=e.data.get("where", ""), conditions=e.data.get("conditions", ""))
                      for n, e in latest.items()]

    reads = [e for e in events if e.type == "code_read"]
    s.codes = list(reads[-1].data.get("codes", [])) if reads else []

    caps = [e for e in events if e.type == "capture"]
    s.captures = [dict(id=e.refs.get("capture", ""), label=e.text, ts=e.ts,
                       sim=bool(e.data.get("sim")), snapshot=e.data.get("snapshot")) for e in caps]
    by_id = {c["id"]: c for c in s.captures}

    for i, e in enumerate(events):
        if e.type != "change":
            continue
        b, a = e.refs.get("before"), e.refs.get("after")
        if not (b in by_id and a in by_id):             # no explicit link: nearest captures either side
            before = [c for j, c in enumerate(events) if j < i and c.type == "capture"]
            after = [c for j, c in enumerate(events) if j > i and c.type == "capture"]
            if not before or not after:
                continue
            b, a = before[-1].refs.get("capture"), after[0].refs.get("capture")
        s.before_after.append(dict(change=e.text, before=by_id[b], after=by_id[a]))

    have_step = {e.refs.get("step") for e in events if e.refs.get("step")}
    for step in STEPS:
        done = step.id in have_step
        if step.id == "baseline_capture":
            done = done or bool(caps)
        elif step.id == "after_change":
            done = any(e.type == "change" for e in events)
        if not done:
            s.not_tried.append(step.title)

    s.attachments = [f"captures/{c['id']}.npz" for c in s.captures if c["id"]]
    return s
```

```python
"""Render a Summary as Markdown or a self-contained HTML page. Renderers never read the case."""
from __future__ import annotations

from html import escape

import numpy as np

from .report import decimate
from .summary import NOT_RECORDED, Summary


def _v(x) -> str:
    return NOT_RECORDED if x in (None, "") else str(x)


def _cap_line(c: dict) -> str:
    snap = c["snapshot"]
    sim = " (SIMULATED)" if c["sim"] else ""
    if not snap:
        return f"{c['id']} {c['label'] or 'unlabeled'}{sim}: verdict {NOT_RECORDED}"
    top = snap["verdict"][0]["title"] if snap.get("verdict") else NOT_RECORDED
    bits = [f"{snap['revs_good']}/{snap['revs']} good revolutions" if snap.get("revs") else None,
            f"5V ref sag {snap['ref_sag_mv']} mV", f"ground deviation {snap['gnd_dev_mv']} mV"]
    return f"{c['id']} {c['label'] or 'unlabeled'}{sim}: the harness reported \"{top}\" ({'; '.join(b for b in bits if b)})"


def to_markdown(s: Summary) -> str:
    v = s.vehicle
    out = [f"# Diagnostic summary: {v.title}", ""]
    if s.empty:
        return "\n".join(out + ["Nothing has been recorded for this case yet."]) + "\n"
    details = [("Engine", v.engine), ("Transmission", v.transmission), ("Mileage", v.mileage),
               ("Modifications", v.modifications)] + ([("VIN", v.vin)] if v.vin else [])
    out += [f"- {k}: {_v(x)}" for k, x in details]
    out += ["", "## Problem", v.problem or NOT_RECORDED]
    if s.symptoms:
        out += ["", "## Symptoms"] + [f"- {x['text']}" for x in s.symptoms]
    out += ["", "## Ruled out"]
    out += ([f"- {r['title']}: {r['reason']}" + (f" (evidence: {', '.join(r['evidence'])})" if r["evidence"] else "")
             for r in s.ruled_out] or ["- nothing yet"])
    out += ["", "## Still open"] + ([f"- {r['title']}" for r in s.open] or ["- nothing listed"])
    if s.confirmed:
        out += ["", "## Confirmed"] + [f"- {r['title']}: {r['reason']}" for r in s.confirmed]
    out += ["", "## Key data"]
    if s.codes:
        out.append("- Codes: " + ", ".join(f"{c.get('code')} {c.get('description', '')}".strip() for c in s.codes))
    out += [f"- {m['name']}: {m['value']:g} {m['unit']}" + (f" ({m['where']})" if m["where"] else "") for m in s.measurements]
    out += [f"- Capture {_cap_line(c)}" for c in s.captures]
    if not (s.codes or s.measurements or s.captures):
        out.append(f"- {NOT_RECORDED}")
    if s.before_after:
        out += ["", "## Before and after"]
        for b in s.before_after:
            out += [f"- After \"{b['change']}\":", f"  - before: {_cap_line(b['before'])}", f"  - after: {_cap_line(b['after'])}"]
    out += ["", "## Not yet tried"] + ([f"- {t}" for t in s.not_tried] or ["- all guided tests have data"])
    out += ["", "## Timeline"] + [f"- {t['ts'][:16].replace('T', ' ') or 'undated'}: {t['line']}" for t in s.timeline]
    if s.attachments:
        out += ["", "## Attachments (in the case folder)"] + [f"- {a}" for a in s.attachments]
    if s.skipped_lines:
        out += ["", f"Note: {s.skipped_lines} damaged log line(s) were skipped."]
    out += ["", "_The verdicts are measurements and rule-based findings from a diagnostic tool, not a diagnosis._"]
    return "\n".join(out) + "\n"


def capture_svg(data, width: int = 560) -> str:
    """Two stacked traces (crank signal and 5V reference) as inline SVG; no external requests."""
    rows = [(1, "crank", 0.0, 6.0, "var(--crank)"), (3, "5V ref", 2.5, 5.5, "var(--ref)")]
    rows = [r for r in rows if r[0] in data.channels]
    if not rows:
        return ""
    m = (data.t >= data.t[0]) & (data.t <= data.t[0] + 0.8)
    ph, h = 70, 70 * len(rows) + 18 * len(rows)
    parts = [f'<svg viewBox="0 0 {width} {h}" role="img" aria-label="Capture traces">']
    for i, (ch, name, lo, hi, color) in enumerate(rows):
        y0 = 18 * (i + 1) + ph * i
        t, v = decimate(data.t[m], data.channels[ch][m], 700)
        x = (t - t[0]) / max(float(t[-1] - t[0]), 1e-9) * (width - 4) + 2
        y = y0 + ph - (np.clip(v, lo, hi) - lo) / (hi - lo) * ph
        pts = " ".join(f"{a:.1f},{b:.1f}" for a, b in zip(x, y))
        parts.append(f'<text x="2" y="{y0 - 5}" class="lab">{name} ({lo:g}-{hi:g} V, first 0.8 s)</text>'
                     f'<rect x="2" y="{y0}" width="{width - 4}" height="{ph}" class="box"/>'
                     f'<polyline points="{pts}" fill="none" stroke="{color}" stroke-width="1.2"/>')
    return "".join(parts) + "</svg>"

def _li(items) -> str:
    return "<ul>" + "".join(f"<li>{i}</li>" for i in items) + "</ul>" if items else ""


def _cap_html(c: dict, svg: str = "") -> str:
    sim = ' <span class="sim">SIMULATED</span>' if c["sim"] else ""
    return f'<div class="card"><b>{escape(c["id"])} {escape(c["label"] or "unlabeled")}</b>{sim}<br>{escape(_cap_line(c).split(": ", 1)[1])}{svg}</div>'


def to_html(s: Summary, plots: dict | None = None) -> str:
    """`plots` maps a capture id to an inline SVG string (from `capture_svg`)."""
    plots = plots or {}
    e, v = escape, s.vehicle
    body = [f"<h1>Diagnostic summary: {e(v.title)}</h1>"]
    if s.empty:
        body.append("<p>Nothing has been recorded for this case yet.</p>")

        body.append(_li(f"{k}: {e(_v(x))}" for k, x in [("Engine", v.engine), ("Transmission", v.transmission),
                                                          ("Mileage", v.mileage), ("Modifications", v.modifications)]))
        body.append(f"<h2>Problem</h2><p>{e(v.problem or NOT_RECORDED)}</p>")
        if s.symptoms:
            body.append("<h2>Symptoms</h2>" + _li(e(x["text"]) for x in s.symptoms))
        body.append("<h2>Ruled out</h2>" + (_li(f"<b>{e(r['title'])}</b>: {e(r['reason'])}"
                    + (f" <span class='muted'>(evidence: {e(', '.join(r['evidence']))})</span>" if r["evidence"] else "")
                    for r in s.ruled_out) or "<p class='muted'>nothing yet</p>"))
        body.append("<h2>Still open</h2>" + (_li(e(r["title"]) for r in s.open) or "<p class='muted'>nothing listed</p>"))
        if s.confirmed:
            body.append("<h2>Confirmed</h2>" + _li(f"{e(r['title'])}: {e(r['reason'])}" for r in s.confirmed))
        data = []
        if s.codes:
            data.append("Codes: " + e(", ".join(f"{c.get('code')} {c.get('description', '')}".strip() for c in s.codes)))
        data += [f"{e(m['name'])}: {m['value']:g} {e(m['unit'])}" for m in s.measurements]
        body.append("<h2>Key data</h2>" + (_li(data) or f"<p class='muted'>{NOT_RECORDED}</p>"))
        if s.captures:
            body.append('<div class="pair">' + "".join(_cap_html(c, plots.get(c["id"], "")) for c in s.captures) + "</div>")
        for b in s.before_after:
            body.append(f"<h2>Before and after: {e(b['change'])}</h2><div class='pair'>"
                        f"{_cap_html(b['before'], plots.get(b['before']['id'], ''))}"
                        f"{_cap_html(b['after'], plots.get(b['after']['id'], ''))}</div>")
        body.append("<h2>Not yet tried</h2>" + (_li(e(t) for t in s.not_tried) or "<p class='muted'>all guided tests have data</p>"))
        body.append("<h2>Timeline</h2>" + _li(f"<span class='muted'>{e(t['ts'][:16].replace('T', ' ') or 'undated')}</span> "
                    f"{e(t['line'])}" for t in s.timeline))
        if s.skipped_lines:
            body.append(f"<p class='muted'>{s.skipped_lines} damaged log line(s) were skipped.</p>")
    body.append("<p class='muted'>The verdicts are measurements and rule-based findings from a diagnostic tool, not a diagnosis.</p>")
    return (f"<!doctype html><html lang='en'><head><meta charset='utf-8'><meta name='viewport' "
            f"content='width=device-width,initial-scale=1'><title>Diagnostic summary: {e(v.title)}</title>"
            f"<style>{CSS}</style></head><body><main>{''.join(body)}</main></body></html>")
```
