# OBD Watch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Record the PCM continuously while the owner cranks: a passive raw CAN monitor (default) or repeated RPM/voltage polling, saved per session, summarized into the case, standalone or linked to a scope capture.

**Architecture:** A `WatchJob` beside `ObdJob` borrows the standing connection (`HeldTransport`) under the controller's `_obd_lock`. Transports gain `stream()` for monitor mode. Frames go to `sessions/<name>/watches/NNN.jsonl` as they arrive; one `watch` event per watch goes to the case. `CaptureJob` gains a `before_arm` hook so a linked watch is monitoring before the scope arms.

**Tech Stack:** Python 3.11, pyserial, Streamlit (+ `streamlit.testing.v1.AppTest`), official `mcp` SDK 2.x, pytest.

**Spec:** `docs/superpowers/specs/2026-11-20-obd-watch-design.md`

Run tests with the main checkout's venv: `/Users/gnomonic/projects/ls-swap/.venv/bin/python -m pytest` (baseline on this branch: 752 passed).

## Global Constraints

- Never transmit on the CAN bus. `ATCSM0`, `ATSH…`, and all ST commands except `STI`, `STDI`, `STSN` stay refused.
- Allowlist additions are exactly: `ATMA`, `ATCSM1`, `ATCAF0`, `ATCAF1`, `ATD0`, `ATD1`.
- Stop byte is a single space `b" "` (ELM327 ignores spaces at the prompt, so a stray one is harmless). Never a bare CR (repeats the last command).
- Standalone watch: default 20 s, maximum 120 s. Linked watch: no own cap; ends at trigger + capture record seconds + 2 s tail, or when an untriggered capture ends; hard ceiling `settings.wait + settings.seconds + 10`.
- A watch needs a `connected` standing connection: `"Connect to the adapter first."`
- Every decoded CAN value carries `best_effort: True`, its source ID and its decoder version. `0C9` engine speed: `data[1:3]` big-endian × 0.25 rpm, version `"0C9-engine-speed-v1: bytes[1:3] BE x0.25"`.
- Poll mode: `010C` every cycle, `ATRV` every 4th cycle. Poll RPM is labelled `"010C (official)"`.
- Simulated watches carry `sim: True`; one kind (real/simulated) per case, watches included.
- Restore after every monitor exit path: back at prompt, `ATCAF1`, `ATD0`. If restore fails, `connection.mark_cold()`.
- Silence threshold: a stream with no line for 1.0 s ends with reason `"silent"`.

## Review Focus

1. **Adapter browns out mid-crank** (reset banner, or the Bluetooth link drops mid-stream raising `ObdNoAdapter`): the watch must end `stopped` with what it had saved, never `error` with nothing. Test in Task 5 (`test_reset_mid_watch_keeps_frames_and_marks_cold`, `test_link_drop_mid_stream_keeps_frames`).
2. **Owner presses Stop within the first second**, before any frame arrives: Stop keeps an empty watch rather than crashing on empty summaries. Test in Task 5 (`test_stop_before_any_frame_saves_an_empty_watch`).
3. **Partial and junk lines** (`SEARCHING...`, `CAN ERROR`, half a frame split across reads): kept raw, never decoded, never crash. Tests in Tasks 2 and 3.
4. **Owner deletes the session or switches session while a watch runs:** delete is refused; the watch keeps writing to the session it started on. Test in Task 6 (`test_watch_writes_to_the_session_it_started_on`).
5. **A read requested right after a watch** gets normal replies (restore worked), including after an overflow. Test in Task 6 (`test_a_read_after_a_raw_watch_gets_normal_replies`).

**Interfaces:**
- Produces:
  - `@dataclass class StreamEnd: reason: str; tail: str = ""`. `reason` ∈ `"stopped"` (stop event), `"time"` (max_seconds), `"silent"` (no line for `silence_s`), `"prompt"` (adapter returned to `>` itself), `"buffer_full"`, `"reset"` (a line containing `LV RESET`, or starting `ELM327`/`STN` mid-stream).
  - `Transport.stream(cmd: str, on_line: Callable[[float, str], None], stop: threading.Event, max_seconds: float, silence_s: float = 1.0) -> StreamEnd`. Base raises `NotImplementedError`; `DelegatingTransport` passes through (so `HeldTransport` works).
  - `SerialTransport.stream`: `allowlist.check(cmd)`, write `cmd + "\r"`, split on CR, call `on_line(time.time(), line)` for each non-empty line except the echo of `cmd`. When it ends by `stopped`/`time`/`silent`, write `b" "`, read until `>` (2 s), then call `self._resync()`. `_resync()`: `send("ATI", 2.0)`; if the reply contains `?`, send `ATI` once more; if it still lacks `ELM327`, raise `ObdTimeout("The adapter did not come back after monitoring.")`. `"prompt"`, `"buffer_full"` and `"reset"` endings write no stop byte. The stop byte is written via `self._ser.write(b" ")` directly; `send` never writes unlisted bytes.
  - `LoggingTransport.stream`: logs `>> <cmd>`, an event `watch stream started`, and on return an event `watch stream ended (<reason>, <n> lines)`. It does not log individual lines.
